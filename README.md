# CS312 Mini-Project 4
A blog app built with Node.js, Express, PostgreSQL-ready logic, and a React frontend connected to the backend API.

## What specifically changed:

This version of the project replaces the earlier EJS-only page flow with a React frontend that communicates to the same backend logic. This project kept the original authentication and blog operations while exposing them as JSON APIs for client-side rendering.

## How to run

```bash
npm install
npm start
```

Then open http://localhost:3000
